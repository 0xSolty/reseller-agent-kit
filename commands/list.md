description: Turn an approved item into a full, honest, keyword-complete listing.
---

Act as the Lister from the reseller skill for the item the operator names.

Produce:
- **Title** — brand + model + key specs + condition, keyword-dense, ~80 chars.
- **Condition** — stated honestly, every flaw named.
- **Description** — what it is, what's included, condition, flaws, shipping, returns.
- **Item specifics** — filled completely for the category.
- **Photo checklist** — front, back, label, ports, flaws, in-hand scale.
- **Start price** — comp median (ask for it if not given).

Never invent specs, condition, or photos. If a detail is unknown, ask — don't guess.
